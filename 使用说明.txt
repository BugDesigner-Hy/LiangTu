晾图 / LiangTu  使用说明
========================
版本：1.2.1
用途：把蓝盾（Tipray）截图自动挂到屏幕顶部的「晾衣绳」，方便复制、拖到企微/文件夹，完整替代旧版「蓝盾截图助手」。


一、安装与启动
--------------
1. 解压压缩包到任意目录（如 D:\工具\晾图\），不要只放在临时下载文件夹。
2. 双击 LiangTu.exe 启动。右下角托盘区会出现「晾图」图标（托盘提示为「晾图 v1.2.1」）。
3. 本包为自包含版本，对方电脑一般无需再装 .NET。
4. 首次启动会弹出三步引导；建议在托盘菜单勾选「开机自启」。
5. 若杀毒软件拦截，请将 LiangTu.exe 加入信任/白名单。


二、与旧版「蓝盾截图助手」互斥（重要）
------------------------------------
晾图与旧版 PowerShell「蓝盾截图助手」都会自动点「另存为」，同时运行会互相抢对话框。

- 启动时若检测到旧助手（AutoSave-LdScreen），会提示一键停止并关闭其开机自启，请选「是」。
- 也可随时：托盘右键 →「停止旧版蓝盾截图助手」。
- 请勿再同时运行旧版启动脚本/bat。


三、日常截图流程
----------------
1. 截图：可按晾图「截图快捷键」（默认 Ctrl+Alt+A，托盘可改），晾图会转发给蓝盾的 Ctrl+Alt+P；也可直接按蓝盾原键。
2. 在蓝盾里点保存；晾图会自动确认「另存为」（BMP），默认写入收件箱并挂到顶绳。
3. 保留蓝盾加密原文，不再转换成明文 PNG；拖出/复制走原文件。
4. 新截图挂上后，晾衣绳会短暂展开便于操作。
5. 托盘右键可切换「衣夹样式」「绳子材质」「照片样式」「绳头挂饰」，立即换外观，无需重启。


四、晾衣绳显隐与多显示器
------------------------
展开 / 收起方式（任选）：
- 鼠标贴到屏幕最顶边
- 快捷键（默认 Ctrl+Alt+T，可在托盘改）
- 托盘双击图标，或右键 →「显示/隐藏晾衣绳」

多显示器：
- 拖动绳子本身，或拖两端金色圆点，可把绳子移到另一块屏幕（按该屏宽度/DPI 重新排布）
- 鼠标贴到另一块屏幕的顶边，绳子也会跟过去
- 托盘 →「移到显示器」可直接选择目标屏幕

空绳 / 折叠后的短绳：靠右显示，闲置一段时间会自动缩到屏幕外，只留一点「露头」；鼠标再贴顶即可拉出。


五、照片操作
------------
前排常显最多 8 张；更多截图收在右侧「+N」里。
- 点击「+N」展开列表，再点其中一张可挂回前排
- 托盘或界面可「折叠全部截图 / 展开全部截图」

拖拽说明（换位 / 拖出）：
- 沿绳子左右水平拖动：换位置（夹子保持夹着；松手落位）
- 往下拉开夹子 / 拖出窗口：进入文件拖出（企微 / 文件夹 / 桌面）
- 不再用「松开夹子再夹回」换位
- 取下请点照片上方的衣夹（开夹后照片如落叶飘落）；也可右键「删除到回收站」

| 操作           | 效果 |
|----------------|------|
| 单击照片       | 复制到剪贴板（位图 + 文件，可粘贴进企微等） |
| 沿绳子水平拖   | 换位（不产生文件复制） |
| 拉开夹子/拖出窗口 | 以文件形式拖到企微/文件夹/桌面 |
| 点击衣夹       | 开夹脱落；收件箱内文件会进回收站 |
| 双击           | 用系统默认看图应用打开 |
| 长按           | 用「画图」打开以便批注 |
| 右键 → 复制    | 同单击复制 |
| 右键 → 固定在前排 | 钉住，新截图也不会把它挤进「+N」；再点可取消 |
| 右键 → 重命名  | 修改文件名 |
| 右键 → 打开    | 同双击 |
| 右键 → 用画图编辑 | 同长按 |
| 右键 → 在文件夹中显示 | 打开资源管理器并选中该文件 |
| 右键 → 从绳子上取下 | 仅离绳，不删文件（非收件箱路径时） |
| 右键 → 删除到回收站 | 离绳并把文件送进回收站 |

固定说明：已固定的照片左上角有「钉」标记、边框偏金色；前排可见槽位会优先留给固定项。

选择收件箱目录…     更改截图落盘目录
打开收件箱          用资源管理器打开当前收件箱
清理收件箱旧文件     按下方策略立刻清理一次（绳上的图不会删）
收件箱保留策略       关闭 / 7天100张 / 14天200张（默认） / 30天500张

显隐快捷键           可选：
                       Ctrl+Alt+T（默认）
                       Ctrl+Shift+T
                       Ctrl+Alt+L
                       Ctrl+Alt+H
截图快捷键           启用后按下会模拟蓝盾 Ctrl+Alt+P：
                       Ctrl+Alt+A（默认）
                       Ctrl+Shift+A
                       Ctrl+Alt+Q
                       F8
开机自启             登录 Windows 后自动启动晾图
音效                 挂图/复制时播放系统「星号」提示音

衣夹样式             原木夹 / 小夹子（青·木·银） / 长尾夹（蓝·木·银）等（立即生效，含开合动画）
绳子材质             麻绳 / 棉绳 / 尼龙绳 / 金属丝（立即生效，挂点颜色随绳调整）

退出晾图             退出程序


七、收件箱与自动清理
--------------------
默认收件箱：
  %LOCALAPPDATA%\LiangTu\Inbox

默认策略：保留最近 14 天，且最多约 200 张图片。
- 启动后与每次新图挂上后会按策略清理
- 正在挂在绳子上的文件不会被清理
- 被清理的文件进入回收站，可在回收站还原
- 可在托盘「收件箱保留策略」中调整或关闭


八、数据与日志位置
------------------
%LOCALAPPDATA%\LiangTu\
  settings.json     设置（收件箱路径、快捷键、音效等）
  pegged.json       绳子上当前挂着的照片列表
  Inbox\            默认截图收件箱
  logs\             运行日志（托盘可打开）
  preview\          打开加密/异常图片时的临时预览


九、常见问题
------------
Q：点了蓝盾保存但没挂上绳子？
A：1）确认托盘已开「自动确认蓝盾另存为」；2）确认旧助手已停；3）托盘 → 打开日志目录，把当天日志发给维护人。

Q：双击 BMP 打不开 /「找不到应用程序」？
A：晾图会按「资源管理器双击」方式打开蓝盾加密 BMP（系统默认关联）。
   请先设置 Windows 默认打开方式：
   1. 设置 → 应用 → 默认应用 → 按文件类型选择默认值
   2. 找到 .bmp → 选「照片」或「画图」
   也可在资源管理器中右键该文件 → 打开方式 → 选择其他应用 → 勾选「始终使用此应用打开 .bmp 文件」。
   蓝盾加密文件须用系统/蓝盾认可的打开路径；若仍失败，用右键「在文件夹中显示」后在资源管理器中双击试一次。

Q：和企微粘贴/拖拽异常？
A：先单击复制再 Ctrl+V；或直接把照片拖进企微聊天窗口。若文件被蓝盾加密，程序会优先放位图到剪贴板。

Q：快捷键无效？
A：可能与其它软件冲突。托盘 →「显隐快捷键」或「截图快捷键」换一组后再试。

Q：绳子挡住点击桌面？
A：收起绳子后，空白区域可点击穿透；需要操作照片时再展开。

Q：如何完全卸载？
A：托盘退出晾图 → 取消「开机自启」→ 删除程序文件夹；可选删除 %LOCALAPPDATA%\LiangTu\。


十、系统要求
------------
- Windows 10 / 11（64 位）
- 企业环境使用蓝盾截图（可用晾图 Ctrl+Alt+A 转发，或直接 Ctrl+Alt+P）
- 无需安装 .NET SDK（自包含发布包）
